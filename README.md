# PyRef · Python 速查站

> 输入 `operator`、`yield`、`itertools`……即出语法、API 表与示例。

在线访问：**https://py.lx1120.is-a.dev** （备用：https://xie-good.github.io/pyref/）

## 特性

- 🎯 **111 个条目**：35 关键字 / 30 内置函数 / 27 标准库 / 19 语法糖
- 🔍 **即输即搜**：精确匹配 > 前缀 > 包含 > 标签 > 描述 打分排序，`/` 聚焦搜索，↑↓ 选择，Enter 直达
- 📋 **API 速查表**：标准库条目（如 `operator`、`itertools`、`pathlib`）列出核心函数签名
- 💡 **示例 + 坑点**：每个条目带可复制代码块与「注意」提示
- 🔗 **Hash 直达**：`#operator`、`#dataclasses` 直接打开详情页，可收藏、可分享
- 📦 **单文件零依赖**：一个 `index.html` 走天下，GitHub Pages / 本地离线均可

## 使用

```bash
git clone https://github.com/xie-good/pyref.git
# 直接双击 index.html 即可，无需构建
```

键盘：`/` 搜索 · `↑↓` 移动 · `Enter` 打开 · `Esc` 返回
